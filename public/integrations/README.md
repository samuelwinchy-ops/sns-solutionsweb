# Integration marks

Shown in the home page integrations row (components/home/Integrations.tsx), each on an identical white tile.

What was added to the Simple Icons shapes: the brand fill colour (Facebook #0866FF, LinkedIn #0A66C2,
YouTube #FF0000, WhatsApp #25D366), a small white shape behind each so the cut-outs read on a tile, and for
TikTok its cyan (#25F4EE) and red (#FE2C55) offset copies behind the black mark.

The CRM and portal names (onOffice, Justimmo, Propstack, FLOWFACT, ImmoScout24, willhaben, immowelt) are not in
Simple Icons and are set as type, in the dark text colour of each company's own logo, read from its website
on 2026-10-06. All marks are trademarks of their owners and are shown only to name an integration.
